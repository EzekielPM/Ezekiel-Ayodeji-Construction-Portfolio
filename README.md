# Ezekiel Construction Portfolio

Standalone construction portfolio for Olusola Ayodeji Ezekiel.

## Deploy
This is a static site. Deploy the repository root directly to Vercel, Netlify, GitHub Pages, or any static host.

## Current media strategy
Existing project images are referenced from the live Product Manager portfolio so the construction site can go live immediately without duplicating large image files. Jubilee Chalet reserves a media slot for the supplied project walkthrough video, to be added in the next media pass.
